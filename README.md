# SmartLedger

A mobile-first business management and accounting web app for Indian retailers and wholesalers.

## Current app modules
- Dashboard with sales, purchases, expenses, stock valuation and estimated profit
- Sales invoices and purchase bills with item selection, quantity, rate, discount and paid/balance tracking
- Inventory with SKU/barcode field, stock quantity, purchase price and sale price
- Customer and supplier directories with opening balances
- Expense register
- Cash and bank movement register
- Financial summary reports
- JSON backup and restore
- Responsive layout for Android phones and desktop browsers

## Run
Open `index.html` in a browser or deploy the repository as a static website (for example, GitHub Pages).

## Important scope notes
This is an original SmartLedger interface, not a pixel-for-pixel copy of Vyapar. It implements common business-accounting workflows without copying proprietary branding or artwork. The current build stores records locally in the browser on one device. Cloud sync, user accounts, multi-device access, GST filing/e-invoicing integrations, payment gateway, thermal printer integration, WhatsApp/SMS automation and other services requiring credentials or a backend are not yet connected. Always export backups.
